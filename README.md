I'm building a way to measure how people grow psychologically, and a model that follows that growth over time.

## What I'm working on

**A psychological measurement system.** People write short answers to open-ended prompts. The system reads what they wrote, scores it against established frameworks from adult developmental psychology, and checks whether those frameworks agree with each other. The goal is to take work that used to need a trained practitioner and several hours, and make it repeatable and easy to check.

**A model of how people change.** One measurement is a snapshot. I care more about the whole movie. The model follows each person across many sessions, keeps a running estimate of where they are, and gets more confident as more data comes in. It stays quiet about someone's path until there is enough data to back it up.

**Testing the model before trusting it.** Before any of this touches real people's data, I test it on simulated groups where I already know the right answer. That is where I learned one of the most useful things so far: a pattern that looks like a stable place people settle into is not always one. The only way to tell is to see what happens after something pushes on it.

## How I work

I decide ahead of time what would prove me wrong. A result counts only if it holds up on data the model has not seen. If the data is not there yet, the feature stays off.
